# Portafolio Web Personal - Henry Alvarez Aquije

## Descripción

Portafolio web personal moderno, profesional y responsivo desarrollado con **HTML5**, **CSS3** y **JavaScript Vanilla**. Diseñado para presentar información personal, habilidades técnicas, proyectos desarrollados y datos de contacto de manera elegante e interactiva.

## Secciones del Portafolio

1. **Header** - Navegación fija con logo, menú y modo oscuro
2. **Hero** - Presentación principal con foto, nombre y botones de acción
3. **Sobre Mí** - Información personal y datos de contacto
4. **Habilidades** - Tarjetas con tecnologías y barras de progreso
5. **Proyectos** - Galería de proyectos con imágenes y tecnologías
6. **Estadísticas** - Métricas profesionales
7. **Contacto** - Información de contacto y redes sociales
8. **Footer** - Copyright y créditos

## Características Técnicas

### HTML5
- Estructura semántica con etiquetas apropiadas
- Meta tags para SEO (description, keywords, author)
- Atributos ALT en imágenes para accesibilidad
- Etiquetas LABEL para formularios
- Navegación accesible con ARIA labels

### CSS3
- **Flexbox** para: Header, Menú, Hero, Habilidades
- **CSS Grid** para: Proyectos, Estadísticas
- **Media Queries** para responsive design:
  - 320px, 480px, 768px, 1024px, 1440px
- **Efectos Hover** en botones, menú y tarjetas
- **Sombras** con box-shadow
- **Transiciones** suaves
- **Animaciones**: Fade In, Slide Up, Scroll Reveal
- **Modo Oscuro/Claro** con variables CSS

### JavaScript (Vanilla)
- Navegación suave (scroll-behavior)
- Header fijo con efecto al hacer scroll
- Menú móvil responsive
- Botón "Volver Arriba"
- Validación de formulario
- Mensaje de bienvenida animado
- Modo Oscuro/Claro con localStorage
- Animaciones Scroll Reveal
- Barras de progreso animadas

## Instalación y Uso

1. Clonar o descargar el proyecto
2. Reemplazar las imágenes en `assets/img/` con las propias
3. Personalizar los datos en `index.html`
4. Abrir `index.html` en cualquier navegador moderno

## Imágenes Requeridas

Colocar en la carpeta `assets/img/`:
- `perfil.jpg` - Foto profesional (recomendado: 400x400px)
- `proyecto1.jpg` - Screenshot del proyecto 1 (recomendado: 600x400px)
- `proyecto2.jpg` - Screenshot del proyecto 2 (recomendado: 600x400px)
- `proyecto3.jpg` - Screenshot del proyecto 3 (recomendado: 600x400px)
